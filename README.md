# Student Performance Predictor 🎓🤖

A Machine Learning model built using Python and Scikit-Learn to predict a student's final marks based on their daily study habits, attendance, and sleep hours.

---

## 🚀 Project Overview
This project utilizes a **Random Forest Regressor** (an ensemble machine learning algorithm) to analyze historical student data and predict expected exam performance. It serves as an introductory project for understanding predictive modeling and regression analysis.

---

## 📊 Features & Input Parameters
The model takes the following features into account:
1. **Hours_Studied:** Daily study hours of the student.
2. **Attendance:** Percentage of classes attended.
3. **Sleep_Hours:** Average daily sleep hours.

---

## 🛠️ Technologies Used
* **Python** 🐍
* **Pandas** (Data manipulation and structuring)
* **Scikit-Learn** (Machine Learning model training and evaluation)

---

## 📈 Model Performance & Evaluation
* **Predicted Marks (for sample 7 hrs study, 88% attendance, 7 hrs sleep):** `80.53`
* **R² Score:** `0.9849` (Indicates high accuracy and strong data fit)
* **Mean Squared Error (MSE):** `2.6626`
